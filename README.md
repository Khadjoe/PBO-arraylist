# PBO-arraylist
Program ini hanya menggunakan satu library bawaan Java yaitu `java.util.ArrayList` pada kelas `Bank`. Library ini berfungsi untuk membuat struktur data penyimpan objek `Customer` yang ukurannya dinamis, sehingga kapasitas jumlah nasabah bisa bertambah secara otomatis tanpa batas maksimal seperti array biasa, serta memudahkan pengelolaan data melalui fungsi bawaannya seperti `.add()` untuk menambah, `.size()` untuk menghitung total, dan `.get()` untuk mengambil data nasabah.
